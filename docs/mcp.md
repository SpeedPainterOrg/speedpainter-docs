# MCP Server & Agent Skills

SpeedPainter exposes a remote Streamable HTTP Model Context Protocol (MCP) server so AI coding and writing agents can create narrated explainer videos directly from local notes or web pages.

- **Official Skill Page**: [SpeedPainter Explainer Video Skill](https://www.speedpainter.org/en/skills/explainer-video)
- **Remote MCP Endpoint**: `https://api.speedpainter.org/mcp`
- **GitHub Repository**: [SpeedPainterOrg/explainer-video](https://github.com/SpeedPainterOrg/explainer-video)

## Install for Claude Code & Codex

```bash
npx --yes github:SpeedPainterOrg/explainer-video
```

After installation, start a new agent session and prompt your assistant with a topic, URL, or local file path to generate a narrated whiteboard video via [SpeedPainter](https://www.speedpainter.org/en).
