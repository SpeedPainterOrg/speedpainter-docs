# Go SDK Reference

Use [`github.com/SpeedPainterOrg/speedpainter-go`](https://pkg.go.dev/github.com/SpeedPainterOrg/speedpainter-go) to validate explainer video requests, estimate scene counts, and build MCP JSON-RPC payloads from Go applications.

```bash
go get github.com/SpeedPainterOrg/speedpainter-go@v0.1.0
```

See the full platform documentation at [https://www.speedpainter.org/en](https://www.speedpainter.org/en).
